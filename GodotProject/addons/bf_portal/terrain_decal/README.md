A plugin for applying top-down orthographic map images to level terrain.

This adds a button in ```CONTAINER_SPATIAL_EDITOR_MENU``` that handles downloading and applying the map images as decal.

This button is only visible in ```.tscns``` belonging to ```res://levels```.

Downloaded images can be found in ```res://addons/bf_portal/terrain_decal/textures```.

Applied decals are added in the level hierarchy as ```Static/MapName_Decal```.
